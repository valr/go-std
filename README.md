# Go Standard Library extensions

[![Go](https://github.com/valr/go-std/workflows/Go/badge.svg)](https://github.com/valr/go-std/actions?query=workflow%3AGo)
[![codecov](https://codecov.io/gh/valr/go-std/branch/main/graph/badge.svg)](https://codecov.io/gh/valr/go-std)

A collection of Go packages extending the standard library

## Packages

- `mathx` — numeric helpers (abs, sum, product)
- `stringsx` — string helpers (reverse, split by multiple separators)
- `strconvx` — conversions between strings and integers
- `slicesx` — slice helpers (filter, map, reduce, intersect, etc.)
- `syncx` — sync helpers (wait with timeout)
- `matrix` — simple matrix transformations
- `util` — tiny helpers (source info, variadic wrapper)

> **Note:** These helpers are intended for convenience and may not be optimized for performance or memory usage.
